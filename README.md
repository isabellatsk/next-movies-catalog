# Mini Catálogo de Filmes

Este é um projeto de **mini catálogo de filmes** desenvolvido com **Next.js** e **React**, que permite buscar e visualizar filmes, além de gerenciar mensagens de erro caso a busca não retorne resultados.


## Funcionalidades

- Buscar filmes por título usando uma API externa.
- Listar filmes encontrados com informações básicas.
- Exibir mensagens de erro quando não há resultados ou ocorre algum problema na busca.
- Atualização dinâmica do estado através de props passadas entre componentes.


## Tecnologias utilizadas

- [Next.js](https://nextjs.org/) - Framework React para aplicações web modernas.
- [React](https://reactjs.org/) - Biblioteca para construção de interfaces.
- [TypeScript](https://www.typescriptlang.org/) - Tipagem estática para maior segurança no código.
- [Tailwind CSS](https://tailwindcss.com/) - Biblioteca de estilização utilitária.
- APIs externas de filmes (como [OMDb API](http://www.omdbapi.com/) ou similar).

## como rodar

1. clonar o repositório
2. rodar `npm install` para instalar dependências
3. rodar `npm run dev` para iniciar o servidor de desenvolvimento

o site estará disponível em `http://localhost:3000`
